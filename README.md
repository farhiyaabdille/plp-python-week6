# PLP Python Week 6

This repository contains my Week 6 Python loop assignment.

- `times_table.py` asks for a number and prints its multiplication table from 1 through 10.
- `skip_counter.py` prints even numbers from 0 through 20 and counts down from 10 to 0 using stepped ranges.
- `loop_hospital.py` repairs three loops and includes a `# FIXED:` explanation for each patient.
- `screenshots/` contains screenshots showing each program's output.

An **off-by-one error** happens when a loop runs one time too many or one time too few because its starting or stopping boundary is incorrect. A helpful `range()` habit is to remember that the stop value is exclusive, so use one more than the desired final number when counting upward (for example, `range(1, 11)` to include 10), and test the first and last values.
